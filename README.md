# نظام محفظة الشعيبي (Al shuibi wallet)

نظام محفظة إلكترونية مبسط ومفتوح المصدر مخصص لإدارة الأرصدة وإجراء عمليات التحويل المالي بين المستخدمين باستخدام Node.js و Express.

## 🚀 المميزات الأساسية
- عرض قائمة المستخدمين والأرصدة الحالية.
- نظام تحويل أموال بين الحسابات مع التحقق من كفاية الرصيد.
- هيكل برمجي منظم وقابل للتطوير.
